Klad-Reimagined Reimplementare modernă (C23 → WebAssembly) a jocului sovietic КЛАД · proiect personal de hobby

▶ Joacă build-ul curent
Merge pe desktop și pe telefon: taste / WASD, sau atingi marginile ecranului. Build-ul WebAssembly e generat din sursă de GitHub Actions la fiecare push.
📦 Cod sursă, disassembly și documentație: github.com/anatoliegolovco/uknt_klad

Ce e gata

  • Target reverse-engineering: КЛАД 1987 (Баранов), УКНЦ МС-0511 (video planar, port @#176640)
  • Fork headless al emulatorului УКНЦ (UKNCBTL fără Qt, C++ + g++) — mașina completă (2× CPU PDP-11, video planar, FDD) rulată fără ecran pentru capturi ground-truth automate
  • Disassembly adnotat УКНЦ + documentație: memory/byte map, registre I/O, mecanica jocului dedusă din assembler
  • Extracție din binar: 10 niveluri (JSON + PNG), tile-uri și sprite-uri
  • Engine propriu scris în C23 + raylib — același cod compilat nativ și WebAssembly (nu doar tooling Python)
  • Gameplay: gravitație, scări, apă = moarte, gardian (AI fidel), scor/vieți, cheie → ușă → ieșire (toate cele 10 niveluri completabile)
  • Animații player (mers / cățărare), sprite gardian distinct, culori scări rezolvate din firmware (alb pe albastru) + mod color/mono
  • Interfață în română (i18n) + comutare versiune, input tastatură + touch
  • CI/CD: build WASM din sursă prin GitHub Actions, deploy automat pe GitHub Pages la fiecare push

Următorii pași

  • Fidelitate decodare planară a câtorva tile-uri (scări / aur încă imperfecte vs. capturile emulatorului)
  • Sunet / efecte
  • Validare side-by-side a fiecărui ecran vs. fork-ul headless

Controale

  • Desktop: săgeți / WASD = mișcare, Space = acțiune
  • Telefon: atingi marginile ecranului (stânga/dreapta/sus/jos)
