De unde vine

Fontul de text nu e stocat ca tabel liniar simplu în ROM — generatorul de caractere УКНЦ e separat/stocat special și nu apare în imaginea ROM de 32 KB. Deci sursa fidelă sunt pixelii pe care îi desenează emulatorul. Folosind fork-ul nostru headless al emulatorului УКНЦ (UKNCBTL fără Qt), tools/extract_uknc_font.py taie capturi curate de text în celule 8×8 prin detecție de spațiu între cuvinte, verificate glyph-cu-glyph (ex. ЗАГРУЗКА → З А Г Р У З К А).

Descărcări

WOFF2 · web (recomandat) WOFF · web fallback TTF · desktop / OS BDF · bitmap original PNG · atlas JSON · matrice 8×8 .h · array C23
WOFF2/WOFF/TTF sunt vectoriale (fiecare pixel = un pătrat) → clare la orice mărime. Sursa de adevăr a formelor rămâne matricea 8×8 (font/uknc_font.h); webfont-urile sunt generate cu tools/gen_webfont.py.

Cum îl folosești pe web

@font-face {
  font-family: "UKNC KLAD";
  src: url("uknc.woff2") format("woff2"),
       url("uknc.woff")  format("woff");
}
.retro { font-family: "UKNC KLAD", monospace; }
