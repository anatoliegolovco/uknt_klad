# Copyright & personal-use note

This is a **personal, non-commercial** project: reverse engineering and
preserving the КЛАД maze game to understand a piece of legacy Soviet PDP-11
software, and to build an original re-imagining for learning and enjoyment.
There is **no commercial intent**. (This file is an engineering note, not legal
advice.)

## The works involved

| Work | Origin |
|------|--------|
| *Rise Out From Dungeons* (1983, MSX) | ASCII Corp. (JP) |
| КЛАД — Crocodile Software (1991) | Crocodile Software (defunct) |
| КЛАД — Баранов Д.Г. (1987) | Баранов Д.Г. |

КЛАД is a port of *Rise Out*; the binaries studied here are the БК-0010 build.

## What this project does

- **Studies** the original binaries: disassembly, data extraction, and notes,
  for personal understanding of how the game works on the hardware.
- **Preserves** the original material in this repo (binaries, extracted data,
  disassembly) as a personal study/preservation archive.
- **Re-imagines** the game in `src/` with original code, and (planned) original
  art and levels — for the fun and the learning, in a modern C23/WASM engine.
